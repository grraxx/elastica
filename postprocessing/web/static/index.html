About the data

  
The solver's results NPZ. The density maps count the points of the training datasets around each
    node, per 0.01-cube: the cells scheme (solver/refine.py), the iso-energy scheme (solver/refine_iso.py), and the
    energy-shell scheme (solver/refine_shell.py), on one colour scale. Forces are the end reactions (Lagrange
    multipliers); fx > 0 is compression. Snap: p changes sign with a jump (|Δq| > 0.17).
    The page link keeps the layer, field, probe and view, so it can be bookmarked.
